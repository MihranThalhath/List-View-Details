## List View Details

Ever needed to show some extra details of a record in the list view of a model?
This module aims to tackle that problem in a generic way. It helps a user with
admin rights to add extra details in the list view of any model by the new
functionality added by this module.



https://github.com/user-attachments/assets/7807ad1d-147e-41da-bc29-a1c7475e39d8



## Usage

1. Install this module.
2. Ensure that the user has admin rights.
3. Go to Settings -> Technical -> User Interface -> List View Details.
4. If Sales Order module is installed, there will be a sample implementation.
5. Recommended to check the sample implementation for better understanding.
6. Current record will be available in the variable `record`.

## Known Issues

1. Sample Implementation will only be available if this module is installed after
